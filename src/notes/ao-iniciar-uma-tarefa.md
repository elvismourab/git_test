# Ao iniciar uma tarefa como dev

- Sempre procurar a base legal para a tarefa apresentada.
  - Isso pode ser feito?
  - Quais artigos defendem / protegem a implementação desta tarefa?
- Pseudocódigo
  - Qual o fluxo atual (se houver)? 
  - O que será alterado.
  - Qual é o fluxo do usuário?
  - Quais problemas posso encontrar durante o desenvolvimento?
  - Atenção com as decisões arquiteturais (dependências em core modules, ...)
  - O que já existe no código que pode ser reaproveitado?
- Quais tecnologias vou utilizar?
